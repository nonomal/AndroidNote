# 从零到一：Hello-Agents 综合案例完整开发指南

> 本系列文档是为 **零 Python 基础** 的学习者编写的实战教程。目标是带你从"完全不懂"到"独立跑通并理解" Datawhale [Hello-Agents](https://github.com/datawhalechina/hello-agents) 教程第四部分（综合案例进阶）的全部三个项目：
>
> 1. **智能旅行助手**（第十三章）—— 多智能体协作 + MCP 工具 + Web 应用
> 2. **自动化深度研究智能体**（第十四章）—— TODO 驱动研究 + 流式输出
> 3. **赛博小镇**（第十五章）—— 游戏引擎 + 记忆系统 + 好感度系统
>
> 原教程内容采用 CC BY-NC-SA 4.0 协议开源，本系列文档基于其项目架构重新编写讲解，配套官方代码仓库：`datawhalechina/hello-agents` 的 `code/chapter13~15` 目录。学习时请以官方仓库代码为准，本文档负责"讲懂它"。

---

> **配套基础篇**:本系列聚焦原书第四、五部分的综合案例与工程化。原书**第 1~12 章**(智能体原理、LLM 基础、三大范式、框架、记忆与 RAG、上下文工程、通信协议、Agentic-RL、评估)的逐章精讲与手敲教程见 [docs/1 系列](../1/README.md)。如果你是纯零基础,推荐先读 docs/1 的第 1~4 章打地基。

### 两条腿走路:跑通官方项目 + 手敲自研项目

- **05~07 篇(跑通路线)**:官方三个项目有几十个文件(Vue 前端、Godot 游戏),正确练法是"克隆 → 跑通 → 精读 → 改造",不是逐行抄写
- **11~14 篇(手敲路线)**:每种项目原型给你一个**每行代码都完整给出**的同架构自研版(5~8 个文件),从空目录敲到整体运行,四个项目分别对应:工具 Agent、多 Agent 结构化输出(项目一的魂)、Plan-and-Execute(项目二的魂)、多 NPC 记忆(项目三的魂)
- 顺序建议:05~07 每跑通一个官方项目,就手敲对应的自研版(05→12、06→13、07→14),"跑通别人的 + 写出自己的"缺一不可
- **18 篇是手敲路线的终点**:前面手敲的都是"应用",18 篇造的是"框架本身"(对应原书第七章《构建你的智能体框架》),五种范式 Agent + 可 pip 安装,建议完成 11~14 后再挑战
- **19 篇是工程化路线的起点**:11~14、18 篇练的是"功能能跑",19 篇练的是"能上线"——真实 PDF 语料、可量化的检索指标、CI 质量闸门、鉴权限流缓存追踪、容器交付。**这一篇的每个指标和每段输出都是实测的**,面试里最能讲的项目通常是这一类
- **19 与 20 是刻意配对的一组**:19 篇做的是**数据平面**(材料怎么找对、怎么不胡说),20 篇做的是**控制平面**(流程怎么停得住、崩了怎么续、人怎么插手)。20 篇把 13 篇那个能跑的研究智能体用 LangGraph 重写,补上断点续跑、人在环中、时间旅行,并且给状态机配了 27 个**测控制流而不是测模型输出**的测试。两篇的工程纪律完全一致(fail closed、限流、`--workers 1`、只 mock LLM、Docker + CI),区别只在业务问题

## 三、三个项目分别练什么

```
项目一 旅行助手        项目二 深度研究         项目三 赛博小镇
─────────────         ─────────────          ─────────────
多Agent顺序协作        TODO驱动的规划执行       Agent + 游戏引擎
MCP协议接外部API       SSE流式实时推送         记忆系统(短期+长期)
Pydantic数据建模       搜索引擎工具集成         好感度状态机
Vue前端表单/地图       Markdown报告生成        Godot/GDScript入门
```

三个项目共用同一套底座：**HelloAgents 框架（SimpleAgent）+ FastAPI 后端 + 一个独立前端**。学完项目一之后，项目二、三的后端部分你会发现"套路是一样的"。

## 四、学习方法建议

1. **先跑通，再看懂，最后改造。** 每个项目文档都分为"里程碑"，每个里程碑结束都有一个可运行的checkpoint。跑不起来就不要往下走。
2. **手敲代码。** 复制粘贴学不会编程。基础篇的代码必须手敲；项目篇可以对照官方仓库，但关键文件建议自己重写一遍。
3. **善用报错信息。** 排错手册（09 篇）教你读懂 Traceback。90% 的报错，答案就写在最后一行。
4. **控制成本。** 全程使用 DeepSeek / 智谱 / ModelScope 等国内低价或免费 API，完整学完三个项目的 LLM 花费通常在 20 元人民币以内。

## 五、最终你将得到什么

**跑通的(官方项目)**:

- 一个能根据"城市 + 天数 + 偏好 + 预算"自动生成完整旅行计划（含地图、天气、酒店、预算、导出 PDF）的 Web 应用
- 一个输入任意研究主题、自动拆解子任务、搜索全网并生成带引用报告的研究助手
- 一个可以用 WASD 走动、按 E 与"有记忆、有性格、有好感度"的 AI NPC 对话的像素小镇游戏

**亲手敲出来的(每一行都是你写的,11~14、18~20 篇)**:

- 一个带工具调用循环、双层记忆、SSE 流式和聊天界面的完整 Agent 服务
- 一个多智能体并行协作、结构化输出带自修复的旅行规划系统
- 一个 Plan-and-Execute 架构、能联网搜索并生成报告的研究智能体
- 一个多 NPC、有好感度和持久化记忆、信息能在 NPC 间传播的记忆小镇
- 一个自己的 Agent 框架:多提供商 LLM、五种范式、可 pip 安装(18 篇)
- 一个**能上线**的企业文档问答系统:混合检索 + 精排、带引用与拒答、检索指标接 CI 闸门、鉴权限流缓存追踪、Docker 交付(19 篇)
- 一个**有状态可恢复**的研究智能体工作流:LangGraph 状态机、Postgres checkpointer 断点续跑、人在环中审批、时间旅行分叉重跑、27 个控制流测试(20 篇)

**工程与专家能力**:

- 用 uv 管理 Python 项目、用 Docker 打包部署任意服务
- 用 LoRA/QLoRA 微调开源模型,用 Ollama/vLLM 私有化部署并接入自己的 Agent（15 篇）
- 16 类真实线上踩坑的识别与解法、从初级到专家的成长路线图（16 篇）
