# 前言：这本教程讲什么、怎么学

## 一句话总结

《Hello-Agents》是 Datawhale 社区出品的一本**免费开源教程**，教你从零开始亲手打造"智能体"——让 AI 不只是陪你聊天，还能自己动脑规划、动手干活的程序。

---

## 先把三个绕不开的词讲明白

**大语言模型（LLM）**：就是 ChatGPT、DeepSeek 这类聊天 AI 的学名。你可以把它想象成一个"读过全世界的书、特别会说话的大脑"——你问什么它都能答。但它只会"说"，不会"做"。

**智能体（Agent）**：给这个大脑装上手和脚。比如你说"帮我订一张明天去上海的机票"，普通聊天 AI 只能告诉你订票步骤，而智能体会真的去查航班、比价格、完成预订。**一句话：LLM 是嘴，Agent 是嘴 + 手 + 脚。**

**API**：程序之间"打电话"的方式。你写的程序想借用 ChatGPT 的聪明才智，不用自己造一个 AI，只要通过 API 给对方服务器"打个电话"，把问题发过去，答案就传回来。

## 为什么现在值得学这个

前言里有个重要判断：2024 年是"百模大战"元年——各家公司拼命比谁的模型更强；而 **2025 年开启了"Agent 元年"**——大家发现，与其训练更大的模型，不如研究怎么让现有的模型学会自主做事，这才是能真正落地干活的方向。

再往前一步是**多智能体系统（MAS）**：让好几个 AI 组成一个小团队，有的查资料、有的写方案、有的挑毛病，互相配合甚至互相辩论，共同完成单个 AI 搞不定的复杂任务。这被认为是释放大模型全部潜力的"关键钥匙"。

## 这本教程和别的教程有什么不一样

作者观察到一个现象：市面上 Agent 框架和教程满天飞，但大多只教"某个框架的按钮怎么按"，学的人**知其然不知其所以然**——就像只会背一份菜谱，换道菜就傻眼了。

这本教程反着来：**从原理讲起，带你亲手造轮子**。你不仅会用现成的框架，还会自己写出一个智能体框架，真正明白它肚子里是怎么运转的。学完的目标是：从大模型的"使用者"，蜕变成智能体系统的"构建者"。

## 全书五大部分，一条循序渐进的路线

1. **基础篇（第 1~3 章）**：什么是智能体、它的发展历史、大语言模型的基本原理。相当于先认识食材。
2. **单体篇（第 4~7 章）**：动手做出你的第一个智能体，理解它内部的"心智结构"，最后自己写一个框架。相当于学会独立做第一道菜。
3. **高级篇（第 8~12 章）**：给智能体装上记忆、工具、与其他智能体沟通的协议，并学会评估它干得好不好。相当于进阶厨艺。
4. **实战篇（第 13~15 章）**：做三个完整项目——智能旅行助手、自动深度研究助手、AI 模拟小镇。相当于办一整桌宴席。
5. **展望篇（第 16 章）**：毕业设计，独立完成一个属于你自己的多智能体应用。

## 开始之前需要什么基础

官方的期望很低：会一点 Python（一门对新手最友好的编程语言）、大概知道"调用 LLM 的 API"是怎么回事就行。**不需要**懂算法、不需要会训练模型——教程的重点是应用与构建，不是数学推导。如果你完全零基础，先花一两周补一下 Python 入门即可上路。

## 官方给的学习建议

- **一定要动手**。项目的 `code` 文件夹里配套了全部代码，务必亲手运行、调试、改一改甚至弄坏再修好。原文引了一句诗："纸上得来终觉浅，绝知此事要躬行。"
- **举一反三**。学完一个案例，试着把技术套用到你自己感兴趣的真实场景，这才是学习的最终目的。
- **善用社区**。这是开源项目，遇到问题可以去 GitHub 的 issue 区提问，有想法也欢迎参与共建。

## 划重点

- LLM 是"会说话的大脑"，Agent 是"会干活的大脑"，API 是程序间打电话的方式
- 行业焦点正从"训练更强的模型"转向"构建更聪明的智能体"，多智能体协作是未来方向
- 本教程的独特之处：不只教你用框架，而是从原理出发带你亲手造一个框架
- 学习路线五步走：基础 → 单体 → 高级 → 实战 → 毕业设计
- 最重要的一条学习方法：**亲手跑代码，光看不练等于没学**
