# Hello-Agents 原书第 1~12 章：零基础通读 + 从 0 到 1 手敲

> 这个目录对应原书**第一部分到第三部分（第 1~12 章）**的逐章精讲。
>
> 和 `docs/2/` 的区别：`docs/2/` 是"综合案例 + 自研项目"路线（对应原书第四、五部分），**这里是"基础与原理"路线**——把每一章的每个术语讲到零基础能懂，并且每一章都给出**可以从空目录一行行敲出来、敲完就能跑**的代码。
>
> 每篇的固定结构（这就是你要求的"是什么 → 怎么用 → 相关知识"）：
>
> 1. **一句话总结** + **这一章解决什么问题**
> 2. **核心知识点详解**：每个新词先说"它是什么"（打比方），再说"怎么用"（代码/步骤），最后说"相关知识"（和前后章节怎么串）
> 3. **动手环节**：完整代码分节给出，每节末尾一个 ✅ Checkpoint，跑通了再往下
> 4. **踩坑与专家提示**：真实开发里会翻车的地方
> 5. **面试怎么讲**：可以直接背的表述
> 6. **本章小结**

## 环境与花费

- 正文（第 1~12 章）要求 Python **3.10 及以上**（第 3 章的 `list[str]` 写法、第 7 章的框架都要求 3.10+）
- **附录 A 要求 Python 3.12**（它用到了 `datetime.UTC`、`def f[T]()` 泛型语法等 3.12 才有的写法，且示例项目 `pyproject.toml` 里写了 `requires-python = ">=3.12"`）。附录 A 第 1 节会教你用 `uv` 装任意版本的 Python，不影响系统环境
- 除第 11 章的训练环节（需要 GPU，可跳过）外，**所有代码都能在一台普通笔记本上跑**
- 需要一个国内大模型的 API Key（DeepSeek / 智谱 / ModelScope 都行），全部章节跑完的 LLM 花费在 10 元以内
- 第 9、12 章的部分代码**完全不需要联网、不需要 API Key**（纯算法实现），**第 3 章的四个实验、第 8 章和第 11 章的实验全部离线**（第 3 章只有可选的第五个实验要下载 1GB 模型，第 8 章最后接真模型那一步才需要 Key），可以先从这些开始建立信心
- **附录 A 全程不需要 API Key**，除最后的 Docker 部分需要装 Docker Desktop 外全部离线

准备好了就从 [00-前言](./00-前言.md) 开始（没写过 Python 的话，先去 [附录 A](./13-附录A-Python从零到能开发.md)）。
